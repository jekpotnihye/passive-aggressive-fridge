# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note that a smart fridge leaves for its owner: a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

## Entry

> Door opened 23 times. Food taken: none. Conclusion: you came for the light.

## Run

```sh
node main.ts
```

The program writes the entry text to `/output/entry.txt` (1 to 200 characters, one line).
